User guide

How to use kb

kb is the self-hosted, deterministic system of record for everything your AI produces — deliverables, episodic sessions, and curated memory — served by one local daemon through a CLI and a web reader.

Audience: humans + coding agents  ·  Serve alone: docs/guide/  ·  As of: post-v0.24 main

In one minute

  • Install two binaries (kb + kb-embedder), run kb daemon, point it at a folder with kb add.
  • Search with kb search or open http://127.0.0.1:4000/ — hybrid BM25 + vector by default.
  • Three ledgers live in one daemon: artifacts you wrote, sessions that produced them, memories you chose to keep.
  • Loopback is open; a public bind needs a bearer token and a TLS reverse proxy.

What kb is for

If you (or your agent) generate a lot of HTML and Markdown — research notes, design reviews, RFCs, session write-ups — you end up with files that are good alone and hard to find together. kb watches those folders, indexes them for hybrid keyword-plus-meaning search, and serves them safely in a sandboxed reader.

It has two users by design: you and your coding agent. Both talk to the same daemon. Ranking, recall, and digests are deterministic algorithms — no LLM inside the daemon, no phone-home.

Three ledgers, one daemon

LedgerWhat it holdsHow you pull it
Deliverables Rendered HTML/MD artifacts — the library kb search · kb get · web gallery
Episodic sessions Captured agent transcripts (digest-indexed) kb why · kb recollect · sessions UI
Curated memory Agent-explicit facts you chose to keep kb remember · kb recall

Sessions are not auto-injected into prompts. You pull them when you need provenance or “have we done this before?” — that separation is load-bearing.

Serve this guide alone

This directory is self-contained (HTML + one CSS file). From the repo root:

cd docs/guide
python -m http.server 8765
# open http://127.0.0.1:8765/

Or point any static host / reverse proxy at docs/guide/. There are no absolute repo-root links inside these pages — they stay usable when the folder is copied or published by itself.

Not this guide: engineering invariants, HTTP API tables, and frozen design research live under the main repo docs (docs/*.md, docs/research/). This site is the operator surface — how to use kb day to day.

Driving kb from an agent

The CLI is the protocol. Run kb tools for the always-current verb manifest. Claude Code users can add the in-tree marketplace, install kb-memory, and run /kb-setup so capture and recall hooks wire themselves in. Every hook is LLM-free; hooks shell out to kb.
