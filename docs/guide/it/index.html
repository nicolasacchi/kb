Guida utente

Come usare kb

kb è l'archivio di riferimento self-hosted e deterministico per tutto ciò che produce la tua AI — deliverable, sessioni episodiche e memoria curata — servito da un daemon locale attraverso una CLI e un reader web.

Destinatari: umani + coding agent  ·  Serve da solo: docs/guide/  ·  Aggiornato a: post-v0.24 main

In un minuto

  • Si installano due binari (kb + kb-embedder), si avvia kb daemon, si punta a una cartella con kb add.
  • Si cerca con kb search oppure si apre http://127.0.0.1:4000/ — ricerca ibrida BM25 + vector di default.
  • Tre registri convivono in un solo daemon: gli artefatti scritti, le sessioni che li hanno prodotti, le memorie che si è scelto di conservare.
  • Il loopback è aperto; un bind pubblico richiede un token bearer e un reverse proxy TLS.

A cosa serve kb

Se tu (o il tuo agent) generi molto HTML e Markdown — note di ricerca, design review, RFC, resoconti di sessione — finisci con file validi da soli e difficili da ritrovare insieme. kb osserva quelle cartelle, le indicizza per una ricerca ibrida keyword-plus-meaning e le serve in sicurezza in un reader sandboxato.

Ha due utenti per design: tu e il tuo coding agent. Entrambi parlano con lo stesso daemon. Ranking, recall e digest sono algoritmi deterministici — nessun LLM dentro il daemon, nessuna telemetria verso l'esterno.

Tre registri, un daemon

RegistroCosa contieneCome si interroga
Deliverable Artefatti HTML/MD renderizzati — la biblioteca kb search · kb get · galleria web
Sessioni episodiche Transcript di agenti catturati (indicizzati come digest) kb why · kb recollect · UI sessioni
Memoria curata Fatti espliciti dell'agente che si è scelto di conservare kb remember · kb recall

Le sessioni non vengono auto-iniettate nei prompt. Si recuperano quando serve la provenienza o «l'abbiamo già fatto?» — quella separazione è strutturale (non negoziabile).

Servire questa guida da sola

Questa directory è autosufficiente (HTML + un file CSS). Dalla root del repo:

cd docs/guide
python -m http.server 8765
# open http://127.0.0.1:8765/

Oppure si punta qualsiasi host statico / reverse proxy a docs/guide/. Non ci sono link assoluti alla root del repo in queste pagine — restano usabili quando la cartella viene copiata o pubblicata da sola.

Non in questa guida: gli invarianti di engineering, le tabelle HTTP API e la design research congelata vivono sotto la documentazione principale del repo (docs/*.md, docs/research/). Questo sito è la superficie per l'operatore — come usare kb giorno per giorno.

Guidare kb da un agent

La CLI è il protocollo. Si esegue kb tools per il manifest dei verb sempre aggiornato. Gli utenti Claude Code possono aggiungere il marketplace in-tree, installare kb-memory ed eseguire /kb-setup così gli hook di capture e recall si collegano da soli. Ogni hook è LLM-free; gli hook invocano kb da shell.
