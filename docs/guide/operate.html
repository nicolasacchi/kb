Share and export

kb share publishes a file or folder to a static host (Cloudflare Pages + Access by default, or GitHub Pages with --public), or writes a self-contained offline bundle.

kb share path/to/doc.html --gate email:example.com
kb share path/to/folder --public
kb share --list "Q3 design pass" --local ./bundle.zip
kb share path/to/doc.html --page ./out.html     # single scrubbed page
kb share list
kb share revoke <name>
Export always strips <template id="kb-prompt"> — your private generation contract does not leave with the artifact. --no-scrub is a loud opt-out. --with-comments publishes otherwise-private review state; use deliberately.

kb download streams raw source or a folder/kb zip for local use without deploying.

Fleet monitoring

The TUI is retired. Use:

kb fleet status              # health sweep over ~/.config/kb/daemons.toml
kb events --follow           # live SSE tail (Last-Event-ID resume)
kb status
kb metrics
kb pause / kb resume / kb reindex

SPA Settings carries Overview / Pipeline / Traffic / Errors / Live pages for the same signals. Multi-daemon lists live in daemons.toml (CLI) and browser settings (SPA).

Tokens and identity

kb token generate
kb token rotate
kb token show
kb token issue alice           # per-user registry token (username positional)
kb token revoke alice          # drop that user's registry line(s)
kb whoami
kb users

Loopback bypasses bearer checks. Non-loopback requires Authorization: Bearer … (or the configured header). Identity resolves once per request for attribution; it is not a permission system — see Comments → identity.

Health and index lifecycle

kb config show | validate | edit

Where files live

  • Config — ~/.config/kb/kb.toml, bearer token at ~/.config/kb/token, fleet list at ~/.config/kb/daemons.toml
  • State — per-kb sqlite, lance vectors, and .review/ under the XDG state dir (typically ~/.local/state/kb/<kb>/)
  • Models — embedding weights under the XDG cache dir (…/kb/models/)
  • Overrides — KB_HOME, or KB_STATE_DIR / KB_CONFIG_DIR / KB_CACHE_DIR
  • Dim mismatch wipe — stop the daemon, remove $STATE/<kb>/lance/, restart

Production checklist

  • Keep the daemon on 127.0.0.1; put Traefik/Caddy/nginx with TLS in front
  • Bearer token present; never run a public bind with KB_ALLOW_NO_AUTH unless the proxy alone is the gate
  • Set artifact_host_suffix (wildcard cert for *.artifacts.…) and parent_origin to the SPA origin
  • trusted_proxies only when the proxy reaches the daemon off-loopback (e.g. Docker bridge)
  • Optional per-kb outbound scrub strips kb-prompt + redactions for non-loopback artifact requests; kb share always strips the prompt on export
  • Back up state regularly (sqlite + lance + .review)

Authoring must-knows

Artifacts that index and comment well share a short contract (scaffold with kb new --template … --title …):

  • A real, human-readable <title> matching the single <h1> — primary search field and gallery card title.
  • Clean <h2>/<h3> hierarchy with stable kebab ids (no UUIDs or timestamps) so section comment anchors survive regen.
  • <meta name="kb-tags"> and <meta name="kb-category"> for facets.
  • Execution contract inside <template id="kb-prompt">, capped at 8 KB — indexed locally, stripped on public share/export.
  • Sandbox-safe: no <base href>, no target="_top", no window.parent reach-arounds (parent SPA is cross-origin).
