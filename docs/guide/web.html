Web reader

The SPA is the primary human surface: browse, search, read in a sandboxed iframe, explore the atlas, and open comments from one shell.

Gallery state (kb, filters, sort, view) lives in the URL — every view is shareable and reload-safe. Open the command palette with ⌘K / Ctrl-K for search modes and navigation.

Gallery

  • Grid / list — virtualized cards with title, tags, age, reading-progress chip.
  • Filters — tags, folder tree, capabilities, date range, category, read-state.
  • Sort — recent, indexed, title, words, created time.
  • Search — hybrid / keyword / semantic from the palette (same modes as the CLI).

Clickable metadata on an open artifact (tag, category, folder, mtime) deep-links back into a filtered gallery — one URL builder, so chips stay consistent.

Atlas

A 2-D map of a kb: each artifact is a point, colored by cluster, so related work sits near related work. Layout is deterministic (same inputs and seed → same coordinates). Recompute when the corpus has moved a lot:

kb atlas recompute --kb NAME
kb atlas recluster --kb NAME --k 8    # retune clusters without full layout

Optional map-home shell (?shell=map or Settings → home preference) makes the atlas the primary navigation surface on desktop — opt-in experiment, not the default.

Detail reader

Each artifact loads from its own origin (<id>.artifacts.<suffix>) inside a sandboxed iframe. Same-origin isolation is what makes arbitrary LLM HTML safe to embed.

Local artifact DNS. Defaults: suffix .artifacts.localhost, parent http://127.0.0.1:4000/. If the reader iframe is blank, check that *.artifacts.localhost resolves to loopback: 
getent hosts s01.artifacts.localhost
Many Chromium builds resolve *.localhost without system DNS. If yours does not: dnsmasq with address=/.localhost/127.0.0.1. Production sets artifact_host_suffix (see Start → beyond loopback).

Around the iframe:

  • Context bar — anchor, add-to-list, copy link, share, fullscreen / bare modes.
  • Inspector rail — about / passport metadata, links (outlinks + backlinks), related memories, folder, comments and versions as dock panels.
  • Versions & diff — git, index snapshots, and working tree behind one façade.
  • Reading progress — scroll and per-section dwell; resumes on reopen; feeds list read-state.
  • Split compare (desktop) — ?pane2= for two artifacts, one shared inspector on the focused pane.
Authoring rule for embeds: no <base href>, no target="_top", no window.parent reach-arounds. The parent SPA is a different origin by design.

History and reflection canvas

History is the activity timeline: opens (with scroll), searches, comments. Reflection canvas (?view=canvas) shows four synchronized day tracks — creation, reading, sessions, comments — with a brush that pivots into a normal gallery list scoped to what you selected.

Mobile

At narrow widths the reader is a one-button sheet: the inspect control opens a bottom sheet that hosts inspector, comments, and versions without separate dead-end panels. Capture from a phone (share sheet / SPA capture) is a one-way staging drop into a capture/ folder — not mobile authoring.
