kb gallery — six approaches

one daemon ·
one set of artifacts ·
six readings of
what a gallery
could be.

The first build (Web Gallery) was a faithful read of the spec — cards, top bar, left rail, floating chrome. These five are parallel takes. Each commits hard to a single posture: editorial, terminal, spatial, archival, immersive. Each is a complete loop — gallery surface plus detail page — built around the same artifacts. Pick the bones you want to keep.

00 · the spec build

Web Gallery

The original. Top bar, virtualized grid, hybrid title-glyph cards, four floating-chrome variants for the detail view, ⌘K palette, status pill. A faithful, polished read of the handoff doc — useful as the baseline against which the five below diverge.

 02 · terminal

The Terminal

Full mono, box-drawing characters, prompt-driven. Search is a command, not a field. Detail opens in the same shell. For operators who already live in tmux.

 05 · immersive

The Stack

Each artifact is a full-viewport hero you swipe past. No grid, no thumbnails — the artifact is the card. For a kb you want to encounter, not search.
