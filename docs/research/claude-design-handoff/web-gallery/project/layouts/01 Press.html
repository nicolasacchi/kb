Lead · Live Demonstration

You can see the borrow checker, if you stand in the right place.

Three rules, one picture: drag a scope, watch the lifetimes resolve in real time. A small tool for a question that has cost the language a thousand blog posts.

The Rust compiler’s borrow checker is famously unforgiving and famously hard to teach. The problem is not that the rules are complex — there are only three — but that they apply to a thing programmers cannot ordinarily see. We have variables, references, scopes; we do not have a picture of how they overlap.

This artifact is that picture. Three boxes, draggable. Resize one to extend its lifetime; move another to overlap. The verdict panel updates as you drag. When the rules are satisfied, it says compiles. When they are violated, it says error[E0502], like the compiler would, with the same prose.

The whole thing is one HTML file. There is no framework. The argument is that this is enough.
