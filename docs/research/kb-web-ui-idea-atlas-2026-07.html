How to read this catalog

Each lens was an independent grok-4.5 offload worker researching one external design tradition against a shared preamble: kb's already-shipped surface (nothing here re-proposes existing features) and the hard non-goals (no in-daemon LLM, no multiplayer/CRDT, no accounts, no push/streaks/badges, mobile is reader + capture, no terminal dashboard). Badges: W1–W5 = wildness (5 = nobody ships this), S/M/L/XL = effort. A risk line appears only where an idea flirts with a constraint and names its mitigation. Decisions live in the synthesis; refusal collisions (TTS, offline packs, print, read-next rails, daemon media) are adjudicated there, not here.

Lens 1 — Reading experience (Readwise, Matter, Instapaper, Omnivore)

Long-form readers thrive on evidence-first search (match passages, not summaries), frictionless capture (highlight → cite/list/memory in three clicks), and keyboard-native triage. kb's atlas, lists, reading-progress and session memory are load-bearing primitives for trail walks, heat maps, and comparison splits — no daemon LLM required.

Match-passage search cards W1 M

Search hits show the best-matching body passage with highlights and a §section · score chip, not the static summary; Enter opens at the section with an arrival flash, p peeks the passage in a side sheet.

Inspiration: Raycast's evidence-first results · Fits: command palette + search cards (confirms the board's match-context item)

Highlight → cite / list / memory W2 L

Select text in the reader → popover: copy citation (title §id · path), add to list with note, save highlight. Highlights live in a per-artifact sidecar (same anchor family as comments), get a rail tab, and export as Markdown quote blocks.

Inspiration: Instapaper highlights + Matter export · Fits: reader annotate layer + lists · Risk: reuse review::Anchor; never market export as backup (invariant #9)

Keyboard triage mode (t) W2 M

From inbox / open comments / stale anchors: t enters triage — j/k move, e open, r resolve, l file to list, s snooze-by-date, u undo; a thin strip shows 3/41 · triage · ?. A processing loop for agent-produced volume, zero gamification.

Inspiration: Readwise triage inbox · Fits: UI choreography over existing mutations (confirms the board's triage item)

Focus tunnel (section monologue) W3 M

Reader chrome collapses to the current h2/h3 only, dimmed prev/next titles as scrubbers, progress as a 1px hairline; n/p jump sections. Built for 4k-word LLM reports where TOC + rail is noise.

Inspiration: Instapaper full-screen / Matter focus · Fits: detail iframe + TocSpy; tunnel is parent chrome, artifact CSS untouched

Clip library (portable reading pack) W3 L

A /clips surface aggregating highlights + list entries + pinned comments into an ordered pack of quote cards; one-click export to a single self-contained HTML/Markdown with relativized links.

Inspiration: Matter export, Omnivore packs · Fits: kb-list/1 import-export + share strip rules · Risk: outbound must strip kb-prompt; "pack", never "backup"

Heat atlas (read × semantic map) W4 M

Atlas nodes tint by dwell/completion (cold unread → hot finished), size by word count; shift-click multi-select → new list from selection. Answers "where haven't I actually read in this neighborhood?"

Inspiration: Readwise library heat · Fits: client-side join of existing progress + atlas coords, no new embedding pass

Echo rail (why am I here?) W4 L

A rail tab stacking backlinks, sessions that touched this path, open comments, supersede lineage, and k-NN atlas neighbors — each a one-line provenance chip with deep link. Structured evidence ranked by recency + link strength, no generated narration.

Inspiration: research-tool provenance without LLM fluff · Fits: rail + sessions/why + graph + atlas neighbors

Semantic trail walk W5 L

][ steps to the nearest unread neighbor in embedding space; a breadcrumb trail is pinnable as a list ("walked 2026-07-18 · 12 hops"); dead ends offer the farthest unread in cluster. Serendipity without a recommender.

Inspiration: linear, keyboard-native discovery over the atlas · Fits: atlas vectors + reading progress + lists

Ghost split (A|B read) W4 XL

?compare= renders two sandboxed iframes with shared scroll ratio and synced sections where heading ids match; palette verb "Compare with…". For design-review vs shipped notes, superseding memory vs old.

Inspiration: code review, applied to longreads · Fits: detail route + versions/notes; same sandbox rules, no CRDT

Local voice read (browser-only) W4 L

Web Speech synthesis over the current section in a parallel plain-text pane (never injecting into the artifact origin); pause/resume, rate, section skip; off by default.

Inspiration: Omnivore TTS · Risk: collides with the recorded TTS refusal — adjudicated in the synthesis; legal shape if ever revisited: client-side only

Sources: Readwise Reader, Matter, Instapaper, Omnivore (product surfaces); kb docs/web-ui.md, docs/reading-lists.md, docs/architecture-invariants.md; the existing idea board's refusals list.

Lens 2 — Spatial canvas (Heptabase, Muse, Kosmik, Kinopio, tldraw)

Spatial tools treat position as meaning: where artifacts live on a user-arranged plane encodes the operator's topology. Heptabase's decisive move — cards owned by a library, reusable across many boards — is kb's highest-leverage pattern: durable artifacts exist; a first-class user-arranged plane doesn't. Method-of-loci research says ordered places + vivid layout improve recall, shippable deterministically.

Pin Atlas — hybrid auto map + hand anchors W2 M

Atlas stays embedding-driven, but the operator can pin cards to absolute (x,y), draw named neighborhood rectangles, freeze clusters; unpinned items reflow under pins as gravity anchors; "reset unpinned" re-runs the deterministic layout.

Inspiration: Kosmik frames, Kinopio boxes, tldraw groups · Fits: extends shipped Atlas; pins are operator data

Board from selection W2 M

From gallery multi-select, list, search, or resurface queue: "Open as board" — an infinite pan surface of those artifacts as cards; drag to arrange, labeled edges, sections. A first-class named object, not a throwaway.

Inspiration: Heptabase whiteboard-from-library, Obsidian Canvas bulk-from-folder · Fits: new Boards surface wired to existing selection sources

Card multi-placement + "where else" jump W1 S

The same artifact appears on many boards without duplication; the inspector lists every placement with a viewport thumbnail; deleting removes the placement, not the artifact.

Inspiration: Heptabase's core model (whiteboards don't own cards) · Fits: inspector rail + Boards

Atomic pull-outs (clip cards) W2 M

Open an artifact in a right split on a board; drag a heading/section or comment thread onto the board as a clip card deep-linking back into source. Clips are indexable notes with backlinks — concept-level spatial work, not document-blob tiling.

Inspiration: Heptabase "drag blocks out as concept cards" · Fits: reader + notes/wikilinks; agents can pre-atomize outside the daemon

Memory-palace walk (loci mode) W4 M

Define an ordered path of loci on a board or atlas pins ("foyer → library → workshop"), each holding artifacts; walk mode is a full-bleed sequential tour with keyboard next/prev. Pull-based review routes.

Inspiration: method of loci (Simonides → Yates), Kinopio's spatial-memory claim · Risk: flirts with streaks if gamified — walks stay pure navigation, zero points

Agent-proposed layouts, operator-owned geometry W4 L

Agents write layout-proposal sidecars (computed outside the daemon); kb renders them as a translucent ghost layer; the operator accepts all, a subset, or drags to override. Accepted geometry becomes ordinary board state.

Inspiration: tldraw programmatic canvas, Heptabase agent skills · Risk: stays legal — daemon only stores/renders; single-writer accept, no CRDT

Decay fog & comment constellation W4 M

Toggleable layers: decay fog (opacity from decay-ranked memory + read-state; stale unread sinks; freshly commented punches through) and comment constellations (orbit dots sized by thread density). Spatial encoding of signals kb already computes.

Inspiration: kb's own resurface scoring made geometric · Fits: atlas + boards + comments + read-state; pull-only

Nested boards as zoom levels W3 L

A board can hold a portal card opening a child board, with a live thumbnail and breadcrumb trail: corpus → topic → investigation without dumping a thousand cards on one plane.

Inspiration: Heptabase sub-whiteboards, Obsidian nested Canvas · Fits: Boards hierarchy; gallery folders seed the tree

Dual-field Atlas — gravity wells vs hand islands W5 XL

Two coupled layers in one viewport: the live embedding Field (read-only) and operator-placed Islands (permanent coordinates); lasso on Field promotes a selection to a new Island; onion-skin both. Machine similarity and human topology, side by side.

Inspiration: method of loci vs embedding maps · Risk: strip any multiplayer kit if tldraw is reused

JSON Canvas I/O W1 S

Import/export boards as .canvas (JSON Canvas 1.0): nodes point at kb artifact ids, edges carry labels; open a kb board in Obsidian and re-import position edits. Storage stays kb-native.

Inspiration: jsoncanvas.org (open MIT interchange) · Fits: board serialization; versions-friendly

Sources: heptabase.com + wiki.heptabase.com, obsidian.md/canvas, jsoncanvas.org, kosmik.app, scrintal.com, kinopio.club, tldraw.dev, Wikipedia method-of-loci / spatial-memory.

Lens 3 — Latent-space cartography (Nomic Atlas, Embedding Projector, Distill)

Embedding maps become navigation instruments only when they expose neighborhoods, labels, and selections. Hard rules from the literature: resolve neighbors in the original high-D space; 2-D cluster sizes and inter-cluster distances mislead by design (Distill) — the UI must refuse to imply them; c-TF-IDF is the deterministic label path that fits the no-in-daemon-LLM invariant where Nomic's LLM namer doesn't. (Lens recovered from the worker's on-disk report after a relay failure.)

Continent keywords (c-TF-IDF labels) W2 M

Replace most-frequent-tag cluster labels with class-based TF-IDF over member text; hover expands a ranked term bar with raw tf, idf, and c-tf-idf per term — fully decomposable, no LLM.

Inspiration: BERTopic's ClassTfidfTransformer; Nomic's floating labels (presentation only) · Fits: AtlasView labels; compute in kb-core at recompute, seeded

True-neighbors rail + layout-stress badge W2 M

Click a dot → inspector lists top-k cosine neighbors from embedding space with distance bars; a badge admits "3 of 8 high-D neighbors are far in 2-D" and pulses them. Distill's lesson, taught in-product.

Inspiration: Embedding Projector original-space NN; Distill t-SNE essay · Fits: AtlasInspector (its NN stub already exists)

Semantic zoom continents W3 L

≤6 broad continents at low zoom, the existing ≤12 clusters mid-zoom, c-TF-IDF bigrams + titles up close; [/] step depth without moving the camera. A basemap revealing countries → cities → streets.

Inspiration: Nomic's geographic-map topic hierarchy · Risk: hierarchy must be a seeded deterministic cascade — do not copy Nomic's LLM label step

Lasso → working set W2 M

Hold L, draw a region; a bottom bar offers: open as gallery filter, add to reading list, boost in resurface, copy ids for an agent. Selections compose with facet chips and search; bookmarkable in the URL hash.

Inspiration: Nomic lasso + selection composition; Projector isolate · Fits: AtlasView → gallery facets, lists, resurface inputs

Bookmarkable cameras W1 S

"Bookmark this view" saves pan/zoom/color-mode/cluster-depth/selection as named local presets; b cycles recent. "The memory-system continent at depth 2, unread-only" becomes a one-key return.

Inspiration: Projector's bookmarks drawer · Fits: thin atlas-route surface, localStorage

Terra incognita (density voids) W4 L

Invert the density heatmap: cells sparse in layout and isolated in embedding space light up as dashed void contours labeled by the nearest continents, with a decomposed gap score. Clicking a void yields a copy-to-clipboard brief so an agent can fill the gap — the daemon only detects.

Inspiration: DensMAP density preservation; cartographic negative space · Risk: emits structured gap records; essays are agent-authored outside

Concept axes (custom directions) W4 L

Pick two poles (two artifacts, or two short texts embedded via the existing worker) and reproject the map onto that axis; slider morphs between default layout and axis layout. "Shipped design ↔ open question" becomes a spatial dimension.

Inspiration: Projector custom linear projections · Risk: pole embeds go through the existing embed path, never an in-daemon generative model

Temporal cartographic replay W5 XL

A scrubber steps through index snapshots; points fade in at first-index time; ghost trails show position jumps across recomputes, stabilized with seeded Procrustes alignment so the movie isn't noise. Session polylines reveal which continents were written in which weeks.

Inspiration: Nomic timestamp slicing; embedding-trajectory viz · Risk: store layout snapshots rather than re-rolling UMAP RNG (atlas determinism)

Map-home shell W5 XL

Optional nav.home = atlas: the app opens on the full-viewport map; typing dims non-hits in place; facets and resurface become overlay masks; Enter on a multi-selection opens the gallery as the list projection of the map selection. The gallery ceases to be a separate world.

Inspiration: Nomic map-first curation; Projector isolate · Fits: composition of the earlier steps; desktop-first

Agent weather fronts W5 L

Density isobands colored by authorship weather: warm fronts where agent sessions wrote heavily this week, cool fronts where human curation pressure (comments, anchors, deep reads) concentrates; each front opens a decomposable score panel and the sessions that built it. Cartography of the collaboration itself.

Inspiration: meteorological isobands over kb's session + comment + read-state joins · Risk: pull-only overlays, no achievements framing

Sources: distill.pub/2016/misread-tsne, research.google Embedding Projector post + projector.tensorflow.org, docs.nomic.ai (data maps, controls, topics, curation, selections), maartengr.github.io/BERTopic (algorithm, c-TF-IDF), umap-learn DensMAP docs, arXiv:1611.05469; local AtlasView.tsx/AtlasInspector.tsx/atlas.rs.

Lens 4 — Serendipity & spaced repetition (Readwise Review, FSRS, antilibrary)

Spaced repetition schedules encounters when retrieval is about to fail (FSRS R/S/D; Ebbinghaus). Readwise shows the product shape kb half-owns: pull-only review, frequency tuning, soft discard, no push. The antilibrary (Eco/Taleb) inverts guilt: unread artifacts are research capacity, not debt. Extend the shipped explainable resurface queue with more signal families — never a queue that only grows.

Review mode on resurface W1 S

Card-at-a-time pull session over the top-N queue: show the reason arithmetic, jump to the open comment or scroll-resume offset; acting clears (resolve, finish) — no "mark done" storage.

Inspiration: Readwise Review vs Scroll · Fits: gallery strip + kb resurface --explain, zero new storage

Frequency tuning (weights, not streaks) W2 M

Per-kb / per-tag / per-list multipliers on resurface terms ("show me less of this kind"), one palette surface, every multiplier visible in --explain.

Inspiration: Readwise frequency tuning; FSRS desired-retention as the one knob · Fits: constants already named in kb_core::resurface

On-this-day in corpus W2 M

A calendar facet: artifacts created, last fully read, or sessions active on this month-day ±N years, with honest reasons ("opened 2025-07-18 · 2 open comments then"). A pure date join on stored timestamps.

Inspiration: BBC On This Day; memories-calendar pattern · Fits: history + mtime + session records

Antilibrary shelf W3 S

A first-class "never opened / <5% / zero backlinks" gallery mode framed as research reserve, sorted by potential (backlink gap, tag rarity, age), with humble copy. Decay never applies — the antilibrary must not fade into guilt.

Inspiration: Eco/Taleb antilibrary; tsundoku · Risk: never mixed into debt-queue scoring

Stability ribbon (R without quizzes) W3 M

Inspector shows a tiny deterministic retrievability curve from the last meaningful encounter, half-life varying by event type (comment work > skim). Observation-only FSRS-ish R; no grades.

Inspiration: FSRS R/S; Readwise mastery half-lives · Risk: must stay explainable; never imply measured recall

Leitner lanes for comment debt W2 M

Open comments bucketed into lanes (today / this week / cooling / cold) with bulk-resolve per lane; lanes are presentation over the .review/ store, not new state.

Inspiration: the Leitner card box · Fits: inbox + comments apply

Drunkard's walk on atlas W4 M

Wander mode: biased random walk over wikilinks/backlinks/tags with a pinnable breadcrumb; resurface can inject cold nodes as attractors; self-avoiding bias prevents bouncing.

Inspiration: random walks on graphs · Risk: must not auto-spam history beacons

Forgotten-cluster radar W4 L

Detect weakly-connected components whose idle-days and open-rates are outliers; surface one cluster card ("7 artifacts on X, last touch 112d"), not seven guilt chips; click applies a temporary filter.

Inspiration: community detection + set-level forgetting curve · Risk: labels must be mechanical (shared tags), never LLM titles

Drift heat on status claims W3 L

A resurface cousin for research HTML: artifacts whose status tags / "shipped" prose disagree with git/path truth, with the evidence in the reason line. A pull-only audit strip.

Inspiration: the kb-audit skill's drift signals · Risk: degrade honestly (empty strip) where git is absent

Negative-space memory W5 L

Surface topics/tags/kbs with high write volume and near-zero recollect/search/open over a window — "you author here; you never return" — optionally seeding the wander mode.

Inspiration: Taleb's anti-résumé; retrieval-practice gap · Fits: existing query logs + episodic aggregates

Half-life dial W4 M

One slider scaling all decay half-lives with a closed-form preview ("at 90%: queue ≈ N; at 70%: ≈ M"). No ML fit; simulated offline from current rows.

Inspiration: FSRS desired retention as sole knob · Fits: single-operator deterministic scoring

Session echo cards W5 M

Resurface past session beats, not just artifacts: prompt + decisions + files touched as a review card whose action is open-artifact or kb why. Bridges episodic memory into the same pull strip.

Inspiration: spaced retrieval of episodes · Risk: must not become a second chat log; stays a pull card

Sources: docs.readwise.io (reviewing highlights), open-spaced-repetition ABC-of-FSRS, Wikipedia spaced-repetition/forgetting-curve/antilibrary, Marginalian on Eco, BBC On This Day, random-walk literature.

Lens 5 — Editorial & generative presentation (front pages, colophons, illuminations)

Publication design can elevate a corpus without LLM ephemera: provenance becomes colophon, comments become errata, versions become galley proofs, wikilinks become cartographic edges. Even the wildest ideas here stay rule-deterministic and ride shipped infrastructure (lists, content_hash, atlas, history). (Retry run with capped fetch budget.)

Broadsheet home W2 M

A fifth gallery mode packing the current filter set into a newspaper front page: one lead story (largest type, deck from kb-summary), two features, a briefs column, a continuing-coverage rail of open-comment artifacts. Packing is pure rules on word count, recency, unread progress, comment mass — same inputs, same page.

Inspiration: NYT/Guardian digital fronts · Fits: gallery view mode beside grid/list/atlas/history

Reader folio chrome W1 S

An optional folio density: serif measure locked to ~66ch, running header (kb · folder · section), footer with short-id + scroll %, and a quiet colophon strip (created, hash prefix, session link). Longreads feel published, not "opened in an iframe".

Inspiration: iA Writer; print @page running headers · Fits: detail chrome; colophon folds what the rail already knows

Issue masthead W2 S

Per-kb masthead above the gallery: display name, deterministic "Vol. YYYY · Issue WW" from the ISO week, corpus census, one-line weather ("3 resurfaced · 1 stale anchor"). ?issue=2026-W29 freezes the week slice. Switching kbs feels like switching publications.

Inspiration: magazine mastheads; Are.na channel headers · Fits: gallery chrome + kb switcher

Errata slip layer W4 L

Open comments render as a translucent numbered errata slip pinned to the artifact's top margin (E1…En with jump-to-anchor); resolving tears a line off live over SSE; "errata only" exports as a one-page companion.

Inspiration: publisher errata slips, galley marginalia · Fits: comments layer on detail + comments export

Hash-seeded illuminations W4 L

Every artifact gets a small generative SVG ornament derived only from content_hash + theme tokens: card vignette, reader endpiece, print rule. Same hash → identical SVG everywhere; theme change recolors without reshaping. Decoration-as-identity, no thumbnails or model calls.

Inspiration: manuscript illuminations; identicon families · Fits: cards + detail chrome; seed already on doc rows

Signature binding (quires) W5 XL

"Bind" a reading list into nested signatures: full-bleed opener, continuous folio numbers, blank verso for marginalia, back-matter index from tags + h2 ids; deterministic page breaks; on-screen flipbook and/or CSS-print pamphlet.

Inspiration: codex quires; Vivliostyle paged media · Risk: adjacent to the print-export refusal — catalogued as an art project, not roadmap

Galley-proof versions W4 L

The diff pane as a printer's galley: proof marks (strikethrough, carets, transpose), hunks grouped by section id, numbered margin queries linkable like comments; word-level vs structural toggles. Same git/hash history, presented as editorial production.

Inspiration: galley proofs; Distill revision sidebars · Fits: versions/diff in the inspector

Section atlas (press map) W5 XL

Re-skin the atlas as a city map: clusters as named districts (deterministic top-TF labels), wikilink edges as streets, high in-degree artifacts as landmarks with serif callouts, an "ink density" layer for unread heat. Hovering a district lists its section-front five.

Inspiration: newspaper section geography; cartographic news graphics · Fits: atlas + wikilink graph + history signals

Sources: NYT/Guardian front anatomy, CSS magazine-layout demos, iA Writer, Vivliostyle, Are.na, identicon/hash-art systems, codex-binding tradition, Distill revision UI (retry run; partly from training knowledge).

Lens 6 — Quantified reading & corpus analytics (contribution graphs, Wrapped, Feltron)

Quantified systems succeed as glanceable temporal structure and once-a-year narrative artifacts — never as nags. GitHub's calendar and Spotify Wrapped prove density fields + deterministic annual aggregates; Li/Dey/Forlizzi's stage model says integration barriers kill reflection, not missing charts. Everything below is pull-based and zero-gamification.

Corpus activity calendar W2 M

A 52×7 heatmap with facet toggles (created, versioned, opened, finished, commented, linked-to); hover lists the day's events; click filters the gallery to that day. Density only — no streak counter, no "keep it going".

Inspiration: GitHub contributions; Obsidian heatmap plugins · Risk: gamification — ban current-streak affordances by design

Year-in-corpus (deterministic Wrapped deck) W2 M

A palette command opens a sequential full-screen deck: words + reading-hours completed, top folders by dwell, top hubs, longest finished read, firsts; the final slide exports as a dated HTML artifact so next year's deck can cite it.

Inspiration: Spotify Wrapped structure; Goodreads Year in Books · Risk: daemon computes numbers; an agent may narrate the exported HTML afterwards — never in-daemon

Vital-signs strip W1 S

One quiet strip of live rollups (artifacts · notes-words · median time-to-first-read · read-through % · links/artifact · open threads), each clickable into the surface that defines it; pin 3–5.

Inspiration: Obsidian word-count status bars; Li et al. integration stage · Risk: no health grades — numbers, not judgments

Reading distribution studio W3 M

Histograms and CDFs instead of calendars-of-shame: session-length distribution, time-of-day rose, days-to-finish by length quartile, abandoned-vs-finished funnel; brush a bin to open those sessions' artifacts. Quiet-season annotations, never missed-goal framing.

Inspiration: casual infovis / slow technology · Fits: desktop analytics route over reading + session timestamps

Knowledge growth rings W4 L

Each kb as a tree-ring cross-section: band thickness = net new artifacts + notes per quarter, hue = fraction that later became load-bearing (linked or commented); hover a ring wedge to see what grew that season.

Inspiration: dendrochronology as metaphor · Risk: comparison stays visual morphology, never a score

Ship-wake snapshots W4 L

On a shipped-tagged version (or manual pin), freeze a 1-hop link-graph snapshot; a Wake tab scrubs between snapshots showing edges appearing/thickening with numeric Δ density. "What did publishing this change in the corpus?" as a first-class deterministic diff.

Inspiration: before/after network analytics · Fits: inspector, sibling to versions/diff; append-only snapshot store

Remarkable days W4 M

Up to ~5 statistically marked days per quarter from ranked heuristics (biggest ingest, biggest finish-read, most unusual by embedding centroid distance), each card showing its raw evidence table; a secondary agent-layer CTA copies the stats block into a prompt.

Inspiration: Spotify Wrapped Archive's priority heuristics · Risk: hard split — daemon: heuristics + tables; agent: optional prose

Influence half-life spiral W5 L

An Archimedean spiral (one loop = a quarter): beads at creation date, sized by cumulative inbound attention, fading by a fitted half-life; filter "still hot after 180d" vs "flash bulbs"; a side list shows citing descendants chronologically.

Inspiration: spiral timelines; longevity analytics · Risk: influence is document→document, never person→person; no expiry notifications

Reproducible yearbook artifact W3 L

kb yearbook --year 2025 emits one self-contained HTML artifact (inline SVG calendar, growth rings, hub table, remarkable-days evidence, a machine block with every number + query hash) that byte-matches on re-run at the same corpus head; it indexes like any research card.

Inspiration: Felton annual reports; kb's own artifact contract · Risk: stats/SVG only by default; narration is agent-layer

Multi-facet reflection canvas W5 XL

Four stacked time tracks (artifact spine, reading pulses, session bars, comment/resurface events) under one synchronized brush; brushing three days highlights the joint subgraph of everything touched; saved brushes become named local scenes.

Inspiration: Li/Dey/Forlizzi multi-faceted reflection · Risk: desktop SPA only; scenes are single-operator local state; no LLM summarizer inside

Sources: github.blog contributions post, Spotify Wrapped engineering (Archive 2025), Goodreads Year in Books, obsidianstats heatmap/statistics plugins, Li, Dey & Forlizzi CHI 2010 (ianli.com PDF), Bostock calendar view.

Lens 7 — Keyboard power (Linear, Superhuman, Raycast, Vimium, i3, VS Code)

Speed-first tools make every actionable object addressable: hints, marks, symbols, registers. Linear/Raycast prove purpose-built command surfaces beat flexible chaos; Vimium/vim show marks and registers turn UIs into addressable memory; i3/tmux show spatial workspaces beat tab piles. The scarce resource is rapid, trustworthy navigation — keep every jump explainable.

Hint-mode everywhere (f / F) W2 M

f overlays one/two-key hints on every actionable target (cards, chips, atlas dots, rail rows, comment threads); F opens in a background peek pane; yf copies the permalink under the hint. Vimium's muscle memory over the whole SPA.

Inspiration: Vimium link hints · Fits: a unified hit-target layer over palette + reader + gallery

Named marks + jump ring W3 S

m<letter> marks any artifact/note/session/atlas position; backtick jumps back; uppercase marks are durable operator anchors; a palette subsection lists marks with titles + age; tiny glyphs appear on atlas and folder tree.

Inspiration: Vimium/vim marks; i3 mark/goto · Fits: spatial-instant twin to reading lists

Triage chords with provenance bundles W2 M

Inbox/resurface as pure keyboard lanes: j/k, e dismiss, h snooze via deterministic decay bump, l file, x multi-select then bulk chord; adjacent items auto-bundle on shared folder/kb/session so one e clears a session dump; the status line always shows why the current item scored.

Inspiration: Superhuman triage language; Linear "decide and move on" · Risk: snooze re-scores only — no notifications ever

Split-pane reading workspace W3 L

Cmd+\ splits the stage into 2–4 panes (reader, note, search, atlas slice); Ctrl+h/j/k/l focus; saved layouts (compare-two-RFCs, artifact+backlinks+session) are one chord away.

Inspiration: i3 splits, VS Code grid, tmux · Fits: shell layout over existing routes; single focus owner, no CRDT

Peek-on-hover / peek-on-hint W2 M

Alt-hover opens an inline peek card (title, passport one-liner, first screenful, link counts) without unloading the reader; Alt+Enter promotes to a side pane; works on wikilinks, backlinks, session files, memory ids; every peek carries a provenance footer.

Inspiration: VS Code peek definition/references · Fits: reader + notes + links inspector (confirms the board's hover-preview item)
