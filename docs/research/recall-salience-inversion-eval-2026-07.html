The salience inversion

a measured recall-quality eval of kb's agent memory · Fable frontier run #1 · 2026-07-06 22:50→23:30 CEST · live daemon 127.0.0.1:4000, 42-memory corpus · adversarially verified (2 workflows, 7 agents, ~324k tokens) · status: finding, no code changed

Verdict. On today's corpus, kb's production recall buries the correct memory below its top-5 for 11 of 21 realistic on-topic queries — live-confirmed, 11/11, no replay involved — while the underlying retrieval had already put the right memory at rank 0 in 9 of those 11. The multiplier chain 1/(60+rank) × salience × decay is the cause: with RANK_K=60, retrieval evidence is compressed into a 1.32× scoring band that the corpus's 1.8× salience spread simply overrides. Salience was designed as a prior; in this constant regime it is the verdict. The 2026-06-29 ruling that "ranking is not the constraint, salience is inert" was true on that day's 13-memory near-uniform corpus — and flipped within seven days of graded salience arriving.

1 · Why this experiment exists

Seven days ago, the memory-system review measured the live corpus (2026-06-29: 13 facts, 8 stuck at the 0.5 default) and concluded: "the decay / floor / pin machinery is dormant. Recall ordering is effectively 'return search order.' Smarter ranking yields little until the write side supplies graded salience." It was right — and it named the fix: build the write side (R6, the distiller).

The write side got built. The July review avalanche plus /kb-distill (shipped this morning, db7ce381) tripled the corpus to 42 live memories and graded them: 28 of 42 now sit above the default (histogram: 0.5×14 · 0.55×2 · 0.6×2 · 0.7×3 · 0.75×3 · 0.8×6 · 0.85×5 · 0.9×7). And this morning, during the distiller's acceptance run, recall — even with --no-floor — failed to surface two verbatim pre-existing duplicates that corpus-direct search ranked #1–2. That live incident (recorded as memory 83afc6839cf4) was the smoke. Nobody had ever measured recall quality here: the SQ program benches artifact search; the 06-29 review measured corpus stats. This is the first labeled-query eval of the memory-recall layer itself.

2 · Method

The system under test

Recall = per-corpus hybrid retrieval (top per_corpus = clamp(4·limit, 20, 50), routes/memory.rs:159) followed by a pure re-rank (kb-core memory.rs:161-218): score = 1/(60+rank) · salience · exp(−k·age_days), id-asc tiebreak, cross-corpus dedup keep-best, then truncate(limit). An independent verifier agent re-derived every constant and path from source (40 file:line citations) and confirmed both 2026-06-29 route defects (mtime-as-age, hardcoded 0.5) are fixed on main (RA1/RA3, commits aa611591/0800a370) — this eval measures the repaired system.

Ground truth

Three reader agents each took a 14-memory slice (bodies, no rankings) and wrote 21 labeled queries under anti-circularity rules: situational phrasing ("some artifacts show no backlinks even though other pages clearly link to them — has this come up before?"), no title-token copying, with the right to declare memories non-targets (17 of 42 were). Kinds: 7 gotcha · 5 project-status · 3 operational · 3 preference · 3 dedup-probe. Full set in the appendix.

Exact-rank replay

Naively re-running kb search to reconstruct retrieval order diverged from recall's internal retrieval (0/8 exact-order). Instead the replay inverts the formula: kb recall --no-floor --limit 100 returns the full ranked corpus with scores; since salience and decay are known per memory, rank = 1/(score/(s·dec)) − 60 recovers the daemon's own retrieval ranks exactly. Validation: 8/8 queries reproduce live top-5 order with 0.0000 rank residuals. Alternative policies then re-score those recovered ranks, mirroring the production rank < 20 truncation. The floor never fires on this corpus (min salience 0.5 > threshold 0.15) — verified live.

Burial anatomy (P0's 11 misses)

  • 10 of 11 buried memories had content rank ≤ 2; 9 of 11 were retrieval's #1 answer. Retrieval is healthy; the re-rank undoes it.
  • Buried memories average salience 0.61; surfaced ones 0.85 — the policy systematically punishes honest mid-band grades.
  • Five 0.85–0.9 "SHIPPED report" memories occupy 53 of 105 P0 top-5 slots across the query set. Two buried memories even appeared in other, off-topic queries' top-5s while missing their own — celebrity memories float everywhere except where needed.
  • Per kind: dedup-probes 0/3 (the exact live failure that forced /kb-distill's dual-arm oracle this morning), operational 1/3, preference 1/3, gotcha 4/7, project-status 4/5. The day-to-day kinds suffer most.
  • Live check of all 11: expected memories rank 6–27 at --limit 50 — ranking failures, not indexing failures; --no-floor changes nothing (byte-identical top-5s).

4 · The mechanism, in one paragraph

Within the 20 hits production retrieval feeds the re-rank, relevance spans 1/60 → 1/79 — a 1.32× band. Corpus salience spans 0.5 → 0.9 — 1.8×. Slow decay adds up to ~1.4× against month-old memories. So a 0.9-salience memory at retrieval rank 19 outscores a 0.5-salience memory at rank 0 (0.9/79 = 0.0114 > 0.5/60 = 0.0083): salience can pay for nineteen positions of retrieval evidence. On 06-29, with near-uniform salience, the multiplier was a no-op — "recall = search order" — and the machinery looked dormant. The moment the write side started grading (exactly what that review prescribed!), the dormant multiplier woke up as the dominant term. This is the generalizable law: whenever the corpus's salience spread exceeds the retrieval band (~1.32× under RANK_K=60), recall ordering degenerates toward salience-sorted-membership — on a flat corpus P0 ≡ P1, on a graded one it inverts. It is also a Goodhart loop: honest 0.55–0.7 grades (the distiller rubric's whole point) are precisely the ones buried, so the local incentive is inflation toward 0.9 — which flattens the signal again inside the celebrity tier.

5 · What survived adversarial review — and the honest bounds

A hostile methodology agent, a live-reproduction agent, and an independent metrics agent attacked the finding. Zero fatal flaws; the headline survives (burial live-confirmed 11/11; McNemar 10–0 discordant pairs, p≈0.002). The real bounds:

  • P1 is 20/21, not 21/21. Live recall returns hits outside the replay's 42-memory universe (one cross-corpus duplicate, 2e33ebfcac2c); the replay silently dropped them — a tool defect worth knowing before anyone reuses replay2.py.
  • Query-from-body circularity inflates the content arm. 17/21 targets sit at content rank 0; blind future-agent queries will be harder for retrieval. The burial finding is independent of this (P0 demotes a rank-0 correct answer below plainly irrelevant memories no matter who wrote the query), and the dynamic-range law holds at any retrieval strength — but treat 48% vs 100% as regime-best-case, not universal.
  • Only the strong-retrieval regime is measured. The case salience-as-prior was designed for — ambiguous queries where retrieval is wrong and importance should win — is structurally absent from a labeled on-topic set. The aggregate effect over blind traffic is bounded by, not equal to, these numbers.
  • Snapshot of a moving corpus. The corpus mutated mid-experiment (one target memory has since dropped out of recall entirely); n=21 carries roughly ±20% CIs; all 42 memories are slow-decay and recent, so the decay term is effectively untested. The verdict implicates salience-as-multiplier under RANK_K=60, nothing else.
  • Query mix is a free parameter (17/42 memories untargeted; a "what-shipped-lately"-heavy mix would flatter P0). Manual inspection found no unlabeled-but-valid answers inside any miss top-5, so the labels are sound for what was asked.
