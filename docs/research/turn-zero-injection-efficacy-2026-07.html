Turn-zero memory injection: pointers, not payloads

an A/B/C behavioral test of the kb recall hook · Fable frontier run #2 · 2026-07-07 01:52–02:45 CEST · 36 plan agents + 12 blind judges + 3 verifiers (~1.7M tokens) · sequel to run #1 (the salience inversion) · status: finding, no code changed

Verdict. At turn zero, the production recall hook's injected block is statistically indistinguishable from injecting nothing (fact transmission 1/10 vs 0/10, Fisher p=1.0). Swap the block's contents for content-ranked titles and transmission appears (5/10 lenient, p=0.033 vs none) — the behavioral reproduction of run #1's ranking inversion. But the sharpest result is what a title block transmits when it works: a pointer, not a payload. In 12 of 15 exposed cells the agent's plan explicitly schedules reading the named memory (80% pointer-uptake), while the 80-char truncated title delivers the actionable fact itself far less often (6/15 lenient, ~3/15 strict). The hook's real product is attention direction — and its binding constraint is whether the right title is in the block at all, which is exactly the ranking bug run #1 measured.

1 · Design

Twelve first-person task briefs, each with a ground-truth fact recorded in kb memory (6 briefs where run #1 showed recall surfacing the fact, 6 where it buries it). For each brief, three arms: A — the live production recall top-5, formatted exactly as kb-recall.sh injects it (titles + kb + id, nothing else); B — the top-5 by corpus-direct content ranking (kb search --kb memory-kb), same format; C — no injected block. 36 plan-only agents (no tools, one message) wrote first-steps plans; 12 judges each graded their task's three plans blind (labels shuffled, seed 20260707) against the recorded fact: SPECIFIC / GENERIC / ABSENT / WRONG_DIRECTION, quoting the earning phrase. Actual exposure (target memory's title present in the arm's block) was string-verified per cell (24/24 flags). An audit agent independently re-derived every count (36/36 cells, zero discrepancies; label→arm mapping quote-traced), and a hostile methodology agent graded the claims — its three forced corrections are folded into everything below.

The ambient-context discovery (a finding, not a flaw): subagents always carry the project's CLAUDE.md and the harness's file-based MEMORY.md index. Two tasks' facts live in MEMORY.md — and in those two tasks every arm including no-injection scored SPECIFIC. They were quarantined from the analysis (n=10 clean tasks). Two lessons ride along free: (1) where the two memory systems overlap, the kb injection is redundant — MEMORY.md is doing that transmission today; (2) ambient memory also misleads: one wrong-direction plan traced verbatim to a stale legacy MEMORY.md one-liner (the curl 127.0.0.1:4000 deploy check — a port prod now owns), not to any injected content. Stale index lines are live steering inputs.

3 · Claims the adversarial pass killed or bounded

  • Killed: "noisy injection actively harms." All four WRONG_DIRECTION cells trace to ambient priors or the stale MEMORY.md line — constant across arms — or to judge variance (one near-identical option set graded WD in one arm, GENERIC in the other). No causal harm from the injected block is demonstrated at n=1 per cell.
  • Bounded: this is a turn-zero floor, not end-to-end efficacy. Plan-only agents can't execute the kb get they schedule; in production, a truncated title plus 80% pointer-uptake likely converts to full payload one tool-call later. The verdict grammar lacked a PLANS_TO_RETRIEVE category — the 12/15 pointer count was recovered post-hoc and is this experiment's most optimistic honest number.
  • Bounded: exposure ≠ independent stage. B's within-block rank advantage (target at rank 1 in 6/9 exposed cells vs A's 2/6) leaks ranking quality into the uptake stage; sibling titles in coherent blocks also carry payload. The funnel is the right decomposition; its stage boundaries need within-block rank as a mediator next time.
  • Bounded: rates are conditional on memory-targeted tasks, judge leniency, and prompt demand characteristics (the plan prompt solicits "prior facts you rely on" — symmetric across arms, but it inflates absolute transmission).

4 · What follows (proposals — all gated on triage)

  1. The ranking fix is a prerequisite, now with behavioral evidence. Run #1 showed the inversion in metrics; this run shows the same inversion deciding whether the injection block does anything at all. Stage 1 is the funnel's choke point.
  2. Inject payloads, not truncated titles. The recall JSON already carries the RA4 summary field per hit; kb-recall.sh formats title-only. One hook change — append the summary gloss when present — attacks stage 3 directly. Related write-side hygiene: outcome-first titles (the distill rubric already mandates this; this run measured why) and never letting a CORRECTION memory's title truncate before the correction.
  3. Prune stale MEMORY.md legacy lines. A [STALE]-marked one-liner measurably misdirected an agent. The ambient index is a live steering surface, not documentation.
  4. The two memory systems should divide labor, not duplicate it. Where MEMORY.md carries a fact, injection is redundant; where it doesn't, injection is currently the only channel and it is broken at stage 1. A deliberate split (MEMORY.md = curated evergreen index; kb recall = long-tail + per-kb) beats the accidental overlap.
  5. Next experiment (run-3 candidate): tool-enabled arms measuring end-to-end task outcomes — does the 80% pointer-uptake actually convert? — plus a PLANS_TO_RETRIEVE verdict class and 2–3 plan samples per cell for variance.
