# kb v0.45

Small, independent hardening and tooling units on top of v0.44. Each section
below is one lane.

### N7

- The cloud object-store stack is no longer compiled into `kb` and
  `kb-code-server`. kb only ever opens local filesystem paths, but the
  `lance` dependency was declared with its default features (aws, azure, gcp,
  oss, goosefs, geo, ...), which pulled in opendal, reqsign, the AWS SDK, `rsa`
  and an advisory-affected `quick-xml`. `lance` is now declared with
  `default-features = false`; the dependency count drops from 1002 to 827 packages (binary size was not measured).
  On-disk data is unchanged (no migration, no schema epoch change).
- A new CI step (`cloud-stack-absent`) fails if that stack returns to
  `Cargo.lock` or if arrow/lance stop resolving to a single version.

### N1

- New `kb validate <file>`: an offline check of a sidecar or wire file against the
  versioned protocol registry in `schemas/` (kb-comments/1 and /2, kb-list/1,
  kb-slate/1, kb-proposal/1, kb-recall/1, kbc-findings/1 and /2,
  kbc-review-context/1, kbc-github-export/1, kbc-cmd/1, kbc-theme/1). It never
  edits a file. See `docs/protocols.md`.
