## kb v0.50 and kb-code v9.0 — "One Language"

kb and kb-code now share one interface language: the same 44px bar, labelled
control rows, state cards, icon set and generated themes.

### Before you upgrade

- No migration (kb schema 45, kb-code epoch 46); no config key is required.
- After upgrading the `kb` CLI, run `kb reindex` once. Gallery excerpts now skip
  skip-links, navigation and page headers, but existing rows keep their old
  excerpt until they are reindexed.
- A stored accent colour from earlier versions is ignored; the look is now
  chosen by theme family in Settings.
- Building from source now needs Rust 1.91 or newer. The declared minimum was
  1.86, but the locked dependencies already required 1.91.
- If you are upgrading from v0.48, also run the v0.49 step: `kb sessions
  rescrub`, then `kb sessions rescrub --apply` once.

### Fixes

- **One artifact, one card.** Saving the same artifact more than once in one
  batch could leave duplicate rows in a corpus, which showed up as duplicate
  cards in the Library. The daemon now keeps one row per artifact, and its
  reconcile pass and `kb reindex` remove duplicates already on disk. The
  Library also never draws two cards for the same artifact.

### kb

- **One 44px bar.** The 52px header, 34px context line and 28px status bar
  (114px of persistent chrome) are one bar. Daemon status is a single dot and
  word in it; click it for the daemon name, counts, ingest rate, embedder state
  and warnings.
- **Five labelled doors** replace eleven icon tabs: Library, Search, Memory,
  Worklog (sessions, slates) and Lists (lists, notes).
- **The Library says what it is showing.** A labelled **View as** control picks
  Front page, Shelf, Index, Atlas, Timeline or Canvas (the `?view=` URLs and `g`
  chords are unchanged), with Arrange (sort, group) and Density beside it.
- **A Front Page band** tops the unfiltered Library: lead story, features,
  "On this day" briefs and a Continuing coverage column. It hides when you
  filter, search or sort, and can be collapsed.
- **Calmer cards, a real Index.** Cards show a serif title, a two-line excerpt,
  two tags and one meta line. The Index view has sticky, sortable columns and a
  Columns chooser that remembers your choice per kb.
- **Reader.** The context bar keeps four actions and a More menu (anchor, copy
  link, split, folio, fullscreen, bare, exclude from index). The rail's About
  tab reads Explore, Passport, one Reading line, collapsed Topics.
- **Memory, Worklog, Search, Settings.** Memory rows lead with the memory; the
  worklog rows are title, outcome and one facts line; search says up front when
  a kb has no embedding model; Settings is grouped under This daemon, Pipeline
  and You.
- **Semantic zoom.** Pinch (or Ctrl-wheel) over the Library steps Atlas, Index
  and Shelf; `-` and `=` do it from the keyboard. Settings, Preferences has a
  "pinch to change Library view" switch.
- **Chords teach themselves.** A which-key overlay follows a chord prefix and
  `?` opens a keyboard sheet built from the same registry that binds the keys.
- **Polish.** The unfiltered Library has no header above the Front Page (the
  count sits in the view bar, with Notes beside it); the Search page has one
  search box and a caption when the kb has no embedding model; the Spine's status
  word is the one status home on desktop (its popover has the per-daemon rows and
  fleet metrics, and reads "warn" while there are open errors); category and
  folder labels in the sidebar are readable; reader rail badges sit on their
  icon and highlights no longer overshoot a scrolling table; Memory shows Health
  only once something has been recalled; Lists, Notes and Settings share one page
  frame. Solid accent surfaces (rail count badges, the phone reader's comment
  count, error cards) are filled again, and paper, card and terminal surfaces use
  their intended light and dark colours in every theme.
- **On a phone.** A bottom tab bar (Library, Search, Memory, Lists, Capture), a
  one-column Front Page band, 44px controls in the view bars, card actions as
  three chips along each card's bottom edge on touch devices, and a reader strip
  that keeps More visible on narrow phones.
- **29 themes in 14 families**, shared with kb-code, with `kb-classic` as the
  default.

### kb-code

- **Top bar doors:** Code, Search, Review, Collections, plus Inbox and Settings.
  The 12-item Explore menu is gone; its destinations are on the new
  **Collections** page.
- **Settings page** (`/~settings`): appearance, keyboard, repositories, review
  store, sibling.
- **The quiet reader.** Breadcrumbs move into the top bar and the editor now
  starts about 81px from the top at 1280x720 (was about 147px). The toolbar is a
  labelled row of verbs with the rest under More.
- **The rail has five homes** (Understand, History, Notes, Facts, Review) plus
  All, down from nine tabs. Old tab ids and saved desk state still work.
- **Review diff toolbar:** three labelled clusters, nine visible controls
  (was eighteen).
- **Search page, Home and loading states.** Search is one box and one labelled
  row, with grammar on request and an honest zero-hit card. Home leads with where
  you were and what needs you. Loading, empty and degraded states look the same
  everywhere.
- **The two apps know each other.** kb-code's omnibox has a **Documents** lane
  fed by kb's search, kb's Cmd+K has a "Search code" row, and kb-code follows the
  theme family set in kb until you pick one in kb-code (the picker says
  "Following kb" or "Chosen here").
- **Polish.** The four doors appear on every page and link to the repo you are
  in, else the last one you used; on desktop the right-hand Stripe is the only
  rail switcher; the review diff title has its own row and the drafts tray no
  longer covers the last lines; on desktop, when trails are enabled, the
  trail chip names the state ("Trail off", "Recording", "Trail paused"); the Search page has no duplicate search field
  in the top bar.
- The pre-Desk reader (`?shell=legacy`) is removed; the URL now opens the Desk.

### API

- `GET /api/kbs` entries carry `embedding_model`.
- `PATCH /api/settings` accepts, and `GET` returns, `theme_family`.
- kb-code adds `GET /api/kb/search` and `GET /api/kb/ui`, read-only relays to kb.

### Dependencies

- `zip` moves from 2.4.2 (yanked upstream) to 9.0.3. No user-visible change.
- Security: `katex` is pinned to the patched 0.18.2 in kb's web app, and
  `source-map-js` moves to 1.2.2 in both web apps. Both are build or rendering
  dependencies; no API changes.
- Minor and patch updates to the web apps' CodeMirror, TanStack, Vite and Vitest
  packages.
